# M4 – Jitter-Buffer adaptiv, FEC/PLC, Statistikfenster, VAD, RNNoise

## Stand
- [x] **Adaptiver Jitter-Buffer**
  - Dynamische Puffer-Anpassung basierend auf Netzwerk-Jitter
  - Konfigurierbar: target/min/max delay, expansion/collapse thresholds
  - Verlust-Erkennung durch Sequenzlücken
  - Gleitender Durchschnitt für Jitter-Berechnung
  - Expand bei >5% Verlust, Collapse bei >10% Verlust
  - Recover bei <2% Verlust und <10ms Jitter
- [x] **FEC (Forward Error Correction)**
  - XOR-basierte Parity-Pakete
  - Konfigurierbare Gruppen-Größe (Standard: 4 Pakete)
  - Parity-Erzeugung aus Daten-Paketen
  - Gruppen-Management (start/add/generate/reset)
- [x] **PLC (Packet Loss Concealment)**
  - Exponentieller Amplituden-Abfall (0.95 pro Frame)
  - Wiederholung des letzten guten Frames
  - Maximale Verlustrate (Standard: 200ms)
  - Stille nach Erreichen der Maximaldauer
  - Statistik: Verluste und verborgene Frames
- [x] **VAD (Voice-Activation-Detection)**
  - Energie-basierte Erkennung
  - Null-Durchgangsrate (ZCR) als zusätzliches Merkmal
  - Wahrscheinlichkeits-Score (0.0 - 1.0)
  - Konfigurierbare Schwellwerte
  - Frames-to-Speech/Silence für Stabilität
  - Max. Sprechdauer (Standard: 3s)
  - State-Machine: SILENCE ↔ SPEECH
- [x] **RNNoise-Integration**
  - PIMPL-Struktur für RNNoise
  - Optional (grazie fallback wenn nicht verfügbar)
  - Float-Conversion (Int16 ↔ Float)
  - Konfigurierbare Suppression-Strength (0.0 - 1.0)
  - VAD-Probability aus RNNoise
- [x] **Statistikfenster (Qt6)**
  - Netzwerk: RTT, Jitter, Verlust, Bitrate, Latenz
  - Audio: Abtastrate, Kanäle, Frame-Größe, Lautstärke, Stumm
  - Jitter-Buffer: Verzögerung, Verluste, Gesamtpakete, Jitter
  - VAD: Status, Energie, ZCR, Wahrscheinlichkeit
  - RNNoise: Verarbeitete Frames, Suppression-Strength
  - PLC: Gesamte Verluste, verborgene Frames
  - Protokoll-Log mit Zeitstempeln
  - Auto-Refresh alle Sekunde
- [x] **Tests**
  - JitterBuffer: Initialisierung, put/get, Verlust-Erkennung, adaptive Anpassung
  - FecGenerator: Parity-Erzeugung, Gruppengrenzen
  - PacketLossConcealer: Stille-Erzeugung, Maximaldauer, Paket-Eingang
  - VAD: Stille-Erkennung, Sprache-Erkennung, Statistik, Reset
